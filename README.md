# ContaFlow · Descargas

Aquí se publican los instaladores de **ContaFlow**, la aplicación de escritorio para contadores
que inicia sesión por ti en SUNAT, SUNAFIL, AFPnet y PDT PLAME.

## Cómo instalar

1. Entra a **[Releases](../../releases/latest)** y descarga `ContaFlow-Instalador-<versión>.exe`.
2. Ábrelo. Si Windows muestra "Windows protegió su PC", haz clic en **Más información → Ejecutar de todas formas**.
3. Sigue los pasos: no necesita permisos de administrador.

**Requisitos:** Windows 10 u 11 (64 bits) y Google Chrome instalado.

## Actualizaciones

ContaFlow revisa este repositorio al abrirse y, si hay una versión nueva, te ofrece instalarla
con un clic. Tus clientes, el padrón y las claves guardadas se conservan.
