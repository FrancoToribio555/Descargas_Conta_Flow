Cómo descargar ContaFlow en Google Chrome

Toma menos de un minuto. Son solo 3 pasos.

¿Usas Microsoft Edge? Ver el manual para Edge.

  1. Pulsa "Descargar para Windows"

    En la página de ContaFlow, pulsa el botón azul Descargar para Windows.

  2. Espera que termine la descarga

    Arriba a la derecha se abre Historial de descargas recientes y verás cómo avanza ContaFlow-Instalador. Tarda unos segundos. Si el panel se cierra, ábrelo con el ícono de la flecha hacia abajo.

    Normalmente Chrome no muestra ningún aviso. Si aparece uno, elige Conservar.

  3. Pulsa "Abrir" e instala

    Cuando diga Hecho, pulsa el botón Abrir (el cuadradito con una flecha) y sigue el asistente. No necesita permisos de administrador.

    Si Windows muestra "Windows protegió su PC", pulsa Más información y luego Ejecutar de todas formas.
